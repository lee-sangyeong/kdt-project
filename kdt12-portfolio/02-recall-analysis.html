자동차 리콜 수명주기 분석

한국교통안전공단 자동차 리콜 데이터 9,856건을 수집·전처리하고 차량 나이와 리콜 사유 카테고리를 설계해 차량 수명주기별 품질 이슈를 해석했습니다.

Notion 원문발표자료

Project Profile

역할
팀장, 기획, 수집, 전처리, 분석

자동차 리콜 9,856건

결과
수명주기별 리콜 패턴 해석
9,856건분석한 리콜 데이터

240만대5-6년 구간 리콜 대상 규모

문제 정의

리콜 건수만으로는 품질 리스크의 시점과 규모를 동시에 설명하기 어렵습니다. 출고 후 몇 년 차에 어떤 유형의 리콜이 발생하는지, 사건 수와 대상 차량 규모가 어떻게 다른지 분석 기준을 새로 세웠습니다.

담당 역할

  • 프로젝트 주제와 분석 방향 설정
  • 날짜형 컬럼 변환, 생산연도와 리콜연도 추출
  • 차량나이 = 리콜연도 - 생산연도 파생변수 생성
  • 0-2년, 3-4년, 5-6년, 7-10년, 10년 이상 구간화
  • 2,197개 서술형 리콜 사유를 8개 카테고리로 구조화

분석 흐름

수집한국교통안전공단 리콜 데이터 확보
정제결측치와 날짜형 컬럼 정리
파생변수차량나이와 연식 구간 생성
텍스트 분류리콜 사유를 8개 유형으로 매핑
해석사건 수와 대상 차량 규모를 분리 해석
