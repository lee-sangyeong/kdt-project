자동차·기계·연구개발 채용 데이터 분석

채용공고, 지원자 스펙, 기업 평점과 리뷰 데이터를 수집해 KDT 수료생에게 유리한 기업 후보와 준비 역량을 데이터 기반으로 정리했습니다.

문제 정의

취업 후보 기업을 감으로 고르면 KDT 역량과 기업 요구조건의 연결성을 확인하기 어렵습니다. 정형 채용 데이터와 비정형 리뷰 데이터를 결합해 지원 우선순위를 판단하는 기준을 만들었습니다.

담당 역할

  • 자소설닷컴 지원자/채용공고 데이터 수집
  • 잡플래닛 평점과 리뷰 데이터 분석
  • ADsP, SQLD, 정보처리기사 등 KDT 연계 자격증 기준 정리
  • 전공, 자격증, 평점, 리뷰 기반 기업 후보 도출
  • WordCloud와 평점 그래프를 통한 기업 문화 해석

분석 흐름

크롤링Selenium과 BeautifulSoup으로 데이터 수집
정제기업별 스펙과 공고 정보를 CSV로 정리
지표 설계KDT 연계 자격증과 전공 비율 반영
리뷰 분석긍정·부정 키워드와 평점 구조 확인
추천 후보적합 기업과 준비 방향 도출

기술 스택

직무 연결: 기업 데이터와 사용자 리뷰를 결합해 의사결정 기준을 만든 프로젝트입니다. HR Analytics, 고객 리뷰 분석, 기업 리서치, 시장 분석 업무에서 요구되는 수집-정제-지표화-시각화 흐름을 보여줍니다.
