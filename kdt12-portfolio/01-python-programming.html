현대자동차 차량 정보 조회 GUI

Python Tkinter로 연료 타입과 차종을 선택하면 차량 제원과 이미지를 확인할 수 있는 데스크톱 GUI를 구현했습니다. 파일 구조, 화면 전환, 예외 처리를 한 프로그램 안에 연결한 기초 응용 프로젝트입니다.

문제 정의

차량 정보를 코드에 직접 넣으면 유지보수가 어렵습니다. 따라서 연료별·차종별 폴더 구조를 기준으로 데이터를 분리하고, 사용자가 화면에서 선택하면 프로그램이 해당 제원과 이미지를 동적으로 불러오도록 설계했습니다.

담당 역할

  • Tkinter 기반 홈, 목록, 상세 화면 구성
  • 연료 선택부터 차종 상세 조회까지 사용자 흐름 구현
  • spec.json, spec.txt, 일반 txt 파일 순차 탐색
  • 차량 이미지 로딩, 크기 조정, 이전/다음 순환 탐색
  • 파일 누락, 빈 파일, 이미지 없음 상황 안내 처리

구현 흐름

데이터 구조data_Hyundai 아래 연료별 폴더 구성
화면 전환Frame과 tkraise로 3단계 화면 전환
제원 로딩JSON 우선, TXT fallback 처리
이미지 탐색이미지 목록과 현재 인덱스 관리
예외 처리누락 데이터에서도 앱이 중단되지 않게 처리

기술 스택

직무 연결: 자동차·제조 기업의 내부 업무 도구는 데이터 로딩, 화면 구성, 오류 대응이 함께 필요합니다. 이 프로젝트는 Python으로 데이터를 사람이 확인 가능한 도구로 연결한 기초 구현 역량을 보여줍니다.
