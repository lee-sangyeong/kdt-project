차량 데이터를 사용자가 탐색 가능한 GUI로 구현

Python Tkinter를 활용해 연료 타입 선택, 차종 목록 조회, 차량 제원과 이미지 확인까지 이어지는 데스크톱 프로그램을 만들었습니다. 단순 문법 실습이 아니라 파일 구조, 화면 전환, 예외 처리를 한 흐름으로 연결한 프로젝트입니다.

03

결과와 구현 근거

User Flow
연료 선택에서 상세 조회까지 이어지는 구조
사용자는 홈 화면에서 연료 타입을 고르고, 목록 화면에서 차종을 선택한 뒤 상세 화면에서 제원과 이미지를 확인합니다. 사용 흐름이 명확해 포트폴리오 시연에 적합합니다.
Robustness
파일 누락 상황에서도 앱이 중단되지 않음
spec.json이 없으면 spec.txt, 그것도 없으면 다른 텍스트 파일을 탐색합니다. 이미지가 없거나 경로가 잘못되어도 안내 메시지를 보여주도록 처리했습니다.

직무 연결과 회고

자동차·제조 기업의 내부 업무 도구는 데이터를 단순히 저장하는 것보다 사람이 확인하고 조작할 수 있는 화면으로 연결하는 능력이 중요합니다. 이 프로젝트는 Python으로 데이터 로딩과 사용자 화면을 직접 연결한 기초 구현 역량을 보여줍니다.
