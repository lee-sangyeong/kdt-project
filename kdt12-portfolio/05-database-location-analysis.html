대구 고깃집 창업 입지 분석

대구광역시 고깃집 점포 수, 인구, 공시지가 데이터를 결합해 신규 창업자에게 상대적으로 유리한 입지를 찾은 SQL 기반 상권 분석 프로젝트입니다.

Notion 원문GitHub 코드

Project Profile

역할
고깃집 창업 분석 파트 담당
데이터
점포, 인구, 공시지가
핵심
경쟁 강도와 진입 부담
산출물
후보 지역 도출
SQL테이블 조회, 집계, 조인
1만명당인구 대비 점포 밀도 기준
4분면공시지가와 점포 수 전략 분류
후보군동구·수성구 일부 동 제시

문제 정의

점포가 많은 중심 상권이 항상 신규 창업자에게 좋은 입지는 아닙니다. 공시지가와 경쟁 강도를 함께 고려해 진입 부담이 낮고 공급이 적은 지역을 찾는 것이 핵심입니다.

담당 역할

  • meat_shop 테이블 명세 정리
  • 구·군·동별 고깃집 점포 수 집계
  • 인구 대비 고깃집 밀도 계산
  • 공시지가 기반 초기 비용 부담 해석
  • 평균 공시지가와 평균 점포 수 기준 4분면 전략 분류

분석 흐름

DB 구조화mini_project DB와 meat_shop 테이블 활용
점포 집계구·군·동 단위 점포 수 산출
경쟁 강도(고깃집 수 / 인구) × 10,000
비용 반영공시지가로 진입 부담 판단
후보 도출공급 적고 비용 낮은 지역 우선

기술 스택

SQLSQLiteMySQLDBeaverPythonPandasMatplotlibCSVLocalDataVWorld
해석: 중심 상권은 수요가 커 보여도 경쟁과 비용이 높습니다. 신규 창업자 관점에서는 공시지가가 낮고 점포 수가 적은 지역을 1차 후보로 보는 것이 합리적이라고 정리했습니다.
