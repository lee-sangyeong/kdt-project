Honest Scope
개인 담당이 명확하지 않은 부분은 팀 기준으로 표시
발표자료에서 이상영 개인 담당 슬라이드가 명확히 분리되지 않은 부분은 개인 성과처럼 과장하지 않았습니다. 대신 팀 프로젝트에서 다룬 제조 비전 딥러닝 구조와 의사결정 포인트를 정확히 정리했습니다.
Model Selection
정확도뿐 아니라 속도와 현장 제약을 고려
부품 분류는 정확도와 Macro F1뿐 아니라 FPS와 지연시간을 함께 봤습니다. ResNet50 이상은 속도 부담이 있어 ResNet18이 정확도와 운영 속도의 균형 모델로 해석되었습니다.
정리 원칙: 제조 비전 AI는 “무엇을 맞힐 것인가”에 따라 분류, 탐지, 분할로 나뉩니다. 모델명보다 문제 정의와 평가 기준을 먼저 설명했습니다.

Classification Insight
CNN은 이미지의 2D 구조를 살림
Random Forest처럼 이미지를 평탄화하면 공간적 구조와 질감 정보가 약해집니다. ResNet18은 형상, 금속 질감, 윤곽 정보를 계층적으로 학습해 부품 분류 성능을 높였습니다.
Segmentation Insight
라벨 품질이 모델 성능의 상한을 결정
Bounding box를 색상 마스크로 변환한 라벨은 실제 결함 경계를 정확히 반영하지 못합니다. U-Net 구조를 써도 픽셀 단위 라벨 품질이 낮으면 경계 예측에는 한계가 있습니다.

직무 연결과 개선 방향

자동차 부품 분류와 용접 결함 검사는 제조 품질 자동화의 대표 과제입니다. 이 페이지는 09번 컴퓨터 비전과 12번 자동차 대시보드로 이어지는 딥러닝 기반 제조 AI 이해도를 보여주는 정리본입니다.
— 딥러닝 기본 프로젝트 회고
한계
결함 데이터와 픽셀 단위 정밀 라벨이 부족하면 실제 라인 적용 신뢰도는 제한됩니다.
개선
현장 촬영 데이터, 조명 변화, 클래스별 불량 유형, 픽셀 단위 라벨을 추가하면 모델 신뢰도를 높일 수 있습니다.
실무 가치
분류·탐지·분할을 목적에 맞게 조합하면 검사 자동화, 작업자 보조, 품질 이력 관리로 확장 가능합니다.
