문제 정의

제조 품질검사에서는 부품 분류, 결함 위치 탐지, 결함 영역 분할이 서로 다른 문제입니다. 각 문제 유형에 맞는 모델 구조와 평가 기준을 이해하는 것이 핵심입니다.

정리 범위

  • 자동차 부품 이미지 분류 구조
  • 용접 결함 객체 탐지 구조
  • 결함 영역 픽셀 단위 분할 구조
  • 전통 모델과 딥러닝 모델 비교 관점
  • 데이터 품질, 라벨 정확도, 실시간 추론 관점

모델 선택 흐름

분류부품 종류를 구분할 때 CNN/ResNet
탐지결함 위치를 찾을 때 YOLO
분할결함 영역이 중요할 때 U-Net
평가정확도뿐 아니라 미탐 비용 고려
현장 적용라벨 품질과 추론 속도 검증

기술 스택
