정상 나사 이미지를 기준으로 외관 불량을 탐지하는 파이프라인

나사 이미지의 정상 패턴을 기준으로 전처리, 특징 추출, PCA 차원 축소, 이상 탐지 구조를 설계했습니다. 불량 유형이 충분하지 않은 제조 이미지 환경에서 모든 불량을 외워 맞히는 방식보다 정상 기준에서 벗어나는 샘플을 찾는 전략을 적용했습니다.

My Scope
전처리부터 이상 탐지까지 검사 흐름 설계
이미지 이진화, 회전 정렬, ROI crop, resize/padding, Gaussian Blur 선택, 특징 추출, PCA, One-Class SVM과 Isolation Forest 검토까지 전체 검사 파이프라인을 구성했습니다.
Inspection Strategy
정상 기준 검사 방식 선택
제조 현장은 모든 불량 유형이 충분히 수집되지 않는 경우가 많습니다. 그래서 정상 이미지의 특징 분포를 기준으로 벗어나는 샘플을 이상으로 보는 one-class 접근을 사용했습니다.
핵심: 불량 데이터가 적은 조건에서는 모든 불량 유형을 지도학습으로 구분하기보다, 정상 패턴에서 벗어나는 샘플을 선별하는 방식이 제조 현장에 더 현실적입니다.

Feature Design
형상·질감·윤곽 특징을 결합
HOG는 방향성 있는 경계와 형상, LBP는 표면 질감, 통계 특징은 밝기 분포, 윤곽선 특징은 대상의 외곽 형태를 설명합니다. 서로 다른 특징을 결합해 단일 특징의 한계를 줄였습니다.
Business View
검사 자동화의 전단계로 활용 가능
이 구조는 불량을 최종 판정하는 완성 모델이라기보다 현장 이미지 입력을 표준화하고 이상 후보를 우선 선별하는 전처리·검사 후보 생성 구조로 해석하는 것이 적절합니다.

직무 연결과 개선 방향

제조 외관 검사에서는 데이터 수량보다 입력 품질, 정렬 안정성, 오탐과 미탐의 비용 해석이 중요합니다. 이 프로젝트는 이미지 처리 기초와 이상 탐지 모델링을 하나의 검사 흐름으로 연결한 경험입니다.
— 컴퓨터 비전 제조 검사 프로젝트 회고
한계
조명, 카메라 각도, 배경 변화가 커지면 전통 CV 특징의 안정성이 떨어질 수 있습니다.
개선
실제 라인 이미지와 다양한 불량 유형을 추가하고, Segmentation 또는 Deep Anomaly Detection으로 확장할 수 있습니다.
실무 가치
정상 기준 이상 탐지는 초기 불량 데이터가 부족한 제조 현장에서 검사 후보를 빠르게 좁히는 데 유용합니다.
