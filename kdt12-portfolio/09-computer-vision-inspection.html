Project 09 · Manufacturing Vision

나사 외관 불량 이상 탐지 파이프라인

나사 이미지의 정상 패턴을 기준으로 전처리, 특징 추출, PCA 차원 축소, One-Class 이상 탐지 구조를 설계한 제조 외관 검사 프로젝트입니다.

Notion 원문발표자료

Project Profile

역할
전처리, 특징 추출, PCA, 이상 탐지 설계
데이터
정상 320장 / 불량 119장
핵심
정상 기준 1-Class 검사
축소
16,760차원 → 219차원
320장정상 이미지
119장불량 이미지
95%PCA 정보 유지율
219차원축소된 특징 벡터

문제 정의

불량 유형별 데이터가 충분하지 않은 제조 이미지 환경에서는 모든 불량을 학습하는 지도학습보다 정상 기준에서 벗어나는 샘플을 찾는 1-Class 이상 탐지가 더 현실적일 수 있습니다.

담당 역할

  • 정상 기준 학습 방향 설계
  • 오츠 이진화, 회전 정렬, ROI crop, 리사이즈와 패딩 적용
  • Gaussian Blur 3x3, 5x5, 7x7 비교 후 3x3 선택
  • HOG, LBP, 통계, 윤곽선 특징 설계
  • PCA 차원 축소와 One-Class SVM, Isolation Forest 검토

비전 파이프라인

이진화배경과 나사 영역 분리
정렬회전 차이를 줄여 입력 안정화
ROI검사 대상 영역만 crop
특징 추출HOG, LBP, 통계, 윤곽선 결합
이상 탐지정상 기준에서 벗어난 샘플 탐지

기술 스택

PythonOpenCVscikit-imageHOGLBPPCAscikit-learnOne-Class SVMIsolation ForestNumPy
직무 연결: 불량 데이터가 부족한 제조 현장에서 정상 기준 이상 탐지는 실무적인 접근입니다. 이 프로젝트는 이미지 전처리부터 특징 설계, 차원 축소, 이상 탐지까지 외관 검사 자동화의 핵심 흐름을 보여줍니다.
