서로 다른 개최연도를 하나의 비교 축으로 정렬

올림픽 개최국의 GDP를 절대 연도로 비교하지 않고 개최연도를 0으로 맞춰 -5년부터 +5년까지 상대 성장률을 계산했습니다. 국가 규모 차이를 줄이고 개최 전후 흐름을 읽기 위한 비교 가능한 시각화 프레임을 설계했습니다.

My Scope
GDP 데이터 수집과 국가명 매핑
World Bank GDP 데이터와 올림픽 개최국 데이터를 연결했습니다. Great Britain, United States처럼 데이터 소스마다 다르게 표기되는 국가명을 정규화해 병합 오류를 줄였습니다.
Visualization Logic
절대 GDP가 아닌 상대 성장률로 비교
국가 규모가 다르면 절대 GDP 비교는 왜곡될 수 있습니다. 개최연도 GDP를 기준값으로 두고 각 연도의 증가율을 계산해 개최 전후 흐름을 비교했습니다.
핵심: 미국처럼 여러 번 개최한 국가는 국가명이 아니라 국가명+개최연도 이벤트 단위로 분리해, 1984년 LA와 1996년 Atlanta를 별개의 비교 대상으로 다뤘습니다.

03

해석 결과

Finding
개최가 항상 GDP 성장으로 이어지지는 않음
일부 국가는 개최 전후 성장 흐름이 있었지만 모든 개최국에 일관적으로 적용할 수 있는 패턴은 약했습니다. 특히 동계올림픽은 개최와 경제 성장의 직접 연결성이 더 약하게 나타났습니다.
Finding
GDP 성장률과 메달 성과 연결은 제한적
경제 규모나 성장률이 높다고 메달 점유율이 높아지는 구조도 명확하지 않았습니다. 선수층, 개최국 효과, 종목 특성 등 다른 설명 변수가 필요합니다.
분석 관점확인 내용결론
개최 전후 GDP개최국별로 상승·정체·하락 흐름이 혼재일관 패턴 약함
하계 vs 동계하계는 일부 증가 흐름, 동계는 관계 약함대회 유형별 차이 존재
메달 점유율GDP 성장률과 직접 상관을 보기 어려움경제 지표 단독 설명 한계

05

직무 연결과 개선 방향

서로 다른 국가와 시점을 같은 기준으로 비교하려면 데이터 정렬 기준을 먼저 설계해야 합니다. 이 프로젝트는 시각화가 단순한 그래프 작성이 아니라 비교 가능한 의사결정 프레임을 만드는 작업임을 보여줍니다.
— 데이터 시각화 프로젝트 회고
한계
GDP만으로 개최 효과를 설명하기에는 인프라 투자, 관광, 인구, 산업 구조 같은 변수가 부족합니다.
개선
개최 비용, 관광 수입, 경기장 사후 활용, 국가별 선수단 규모를 함께 결합하면 더 설득력 있는 분석이 됩니다.
실무 가치
서로 다른 기간의 KPI를 기준 시점 0으로 맞춰 비교하는 방식은 제조 설비 도입 전후 성과 분석에도 활용 가능합니다.
