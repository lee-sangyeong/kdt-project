Business Problem
모터 베어링 고장을 사후 대응에서 사전 감지로 전환
생산 설비 모터 베어링 이상은 라인 정지, 품질 저하, 긴급 정비 비용으로 이어집니다. 이 프로젝트는 진동·온도 데이터를 실시간으로 수집하고 이상 스코어, 결함 후보, RUL 추세를 작업자 화면에 제공해 정비 판단을 앞당기는 것을 목표로 했습니다.
Portfolio Position

정리 기준: 발표자료는 별도 파일이 없었고, 사용자가 제공한 로컬 실제 시연용 폴더를 기준으로 파일과 코드 내용을 다시 확인해 작성했습니다.

04

AI 모델 구조: 1D CNN AutoEncoder와 1D ResNet

Anomaly Detection
1D CNN AutoEncoder
입력은 (batch, C, 400) 진동 신호이며, DC775 live는 C=3입니다. Encoder는 Conv1d stride=2로 400→200→100→50으로 압축하고, hidden_dim 64와 latent_dim 32를 거쳐 Decoder의 ConvTranspose1d로 원본 shape를 복원합니다. 입력과 복원값의 MSE를 이상 스코어로 사용합니다.
Fault Classification
1D ResNet balanced sampler
PUBLIC_BEARING_100의 ResNet1D는 stem Conv1d 이후 ResidualBlock1D를 여러 stage로 쌓고 AdaptiveAvgPool1d와 FC classifier로 Normal/Outer/Inner/Ball 결함 후보를 분류합니다. balanced sampler로 클래스 불균형을 완화한 모델이 대시보드 promoted model로 지정되어 있습니다.

한계, 개선 방향, 기업 관점의 의미

이 시스템의 핵심 가치는 장비 한 대를 시연하는 데서 끝나지 않고, 기업 현장 데이터가 쌓일수록 정상 기준과 결함 후보 판단이 해당 기업 설비에 맞게 고도화되는 운영 구조에 있습니다.
— 아진산업 SILI 예지보전 프로젝트 정리
현재 한계
현재 제출 패키지에는 DC775 threshold JSON과 replay session 데이터가 부족합니다. 따라서 모델 구조와 운영 흐름은 확인되지만, DC775 장시간 run-to-failure 성능은 추가 수집이 필요합니다.
개선 방향
설비명, RPM, 볼 개수, 샘플링 Hz를 필수 프로필로 수집하고, normal/outer/inner/ball 라벨별 최소 5건 이상을 쌓아 재학습 후보가 실제 기업 모델로 승격되게 해야 합니다.
기업 가치
현장 설비별 데이터베이스, 이상감지, 결함 후보, RUL 추세, 작업자 경보가 결합되어 정비 우선순위 판단과 생산 중단 리스크 감소에 연결될 수 있습니다.
