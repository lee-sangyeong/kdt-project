Business Problem
위치가 매번 달라지는 부품을 로봇이 직접 보고 집어야 하는 문제
일반적인 고정 자동화는 부품이 항상 같은 위치에 있어야 안정적으로 동작합니다. 이 프로젝트는 작업대 위 파이프, 볼트, 너트의 위치와 방향이 바뀌어도 AI 비전으로 물체를 찾고 실제 로봇팔 좌표로 변환해 피킹·투입·회수 동작까지 이어지도록 구성했습니다.
Portfolio Position
비전, 좌표 보정, 임베디드 제어, 대시보드를 한 흐름으로 연결
단순히 로봇팔을 움직이는 시연이 아니라, 카메라 캘리브레이션, Homography, 로봇팔 기준 좌표 보정, IK, 실제 모터각 보정, CAN 명령, ToF 파지 확인, 디지털 트윈 대시보드까지 제조 자동화 셀의 핵심 흐름을 통합했습니다.
정리 기준: 기술 상세는 최종 시연 프로젝트 파일의 arducam_auto를 기준으로 작성했고, 대시보드는 삼보/sambo_robot/dashboard의 실제 실행 파일과 서버 구성을 함께 반영했습니다.

구분 확인한 파일 / 설정 역할
카메라 ArduCam OV9782, YUYV 1280x720, 작업대 약 64cm 작업대 전체를 촬영하고 파이프·볼트·너트 후보를 검출합니다.

작업대 → 로봇팔 ik_pose.py, H_ARM_POSE, RBF 보정 작업대 좌표를 로봇팔 M1 중심 기준 좌표로 다시 맞춥니다.

03

IK와 실제 모터 제어

Inverse Kinematics
이론 관절각을 실제 자작 로봇팔의 모터각으로 보정
ik.py는 링크 길이, solve_pick, solve_ik, 그리고 M1~M6의 OFFSET/GAIN 보정값을 사용합니다. 이론 IK 값만으로는 자작 로봇팔의 조립 오차와 회전 방향 차이를 맞출 수 없기 때문에, 실제 성공 모터각을 기준으로 명령각을 보정했습니다.
Embedded Control
Raspberry Pi가 판단하고 STM32가 서보와 그리퍼를 구동
Raspberry Pi 5는 AI 검출과 자동 워크플로우를 담당하고, CAN 명령으로 STM32에 목표 동작을 전달합니다. STM32는 STS3215 6축 서보, 그리퍼, 상태 피드백을 처리하며, Arduino Nano는 VL53L0X ToF 센서 정보를 CAN으로 전달합니다.
단계 기술 의미
목표 좌표 입력 로봇팔 M1 기준 x, y, z 카메라 좌표가 아니라 로봇이 실제로 움직일 수 있는 기준 좌표입니다.
IK 계산 solve_pick, solve_ik 목표 위치에 도달하기 위한 이론 관절각을 계산합니다.
모터각 보정 cmd = OFFSET + GAIN * theta 수학 관절각을 실제 서보 명령각으로 바꿉니다.
안전 제한 check_limits, 관절별 범위 제한 기구적으로 위험한 각도 명령을 제한합니다.
파지 확인 VL53L0X ToF, 그리퍼 상태 물체를 실제로 잡았는지 확인하는 센서 기반 흐름입니다.

CNC 가공 중 파이프를 제외하고 볼트/너트만 분류 가공 대기 시간을 활용해 주변 이물을 제거합니다.

Local Dashboard Preview http://127.0.0.1:8766/
Run Script
대시보드_실행.bat 기준 실행
실제 대시보드는 삼보/sambo_robot/dashboard/대시보드_실행.bat가 여는 http://127.0.0.1:8766/ 주소 기준입니다. 이 HTML을 로컬 브라우저에서 열고 배치 파일 서버가 살아 있으면 위 미리보기 영역에 대시보드가 표시됩니다.
Notion Embed Note
노션 공개 임베드는 로컬 주소만으로는 제한됨
Notion은 HTTPS 페이지 안에서 127.0.0.1 로컬 HTTP 서버를 안정적으로 임베드하지 못합니다. 공개 포트폴리오에서 미리보기를 보여주려면 정적 HTML을 GitHub Pages/HTMLPreview에 올리거나, 대시보드 캡처 이미지를 외부에서 접근 가능한 이미지 URL로 연결해야 합니다.
안전 메모: 실시간 로봇 제어 대시보드를 외부 터널로 공개하면 로컬 상태와 제어 기능이 노출될 수 있습니다. 공개 포트폴리오에는 실시간 제어 화면보다 캡처 이미지나 정적 데모 HTML을 사용하는 방식이 안전합니다.

한계, 개선 방향, 기업 관점의 의미

이 프로젝트의 핵심 가치는 로봇팔을 한 번 움직인 것이 아니라, 카메라 검출 결과를 실제 제조 공정 좌표와 로봇 제어로 연결하는 방법론을 구현했다는 점에 있습니다.
— 삼보모터스 AI CNC 로봇팔 자동화 프로젝트 정리
현재 한계
자작 로봇팔은 산업용 로봇 수준의 반복정밀도와 강성을 바로 기대하기 어렵습니다. 실제 공장 도입 전에는 산업용 로봇, 고강성 프레임, 안전 펜스, 인터락, 비상정지 체계가 필요합니다.
개선 방향
실제 삼보 Pipe Part 또는 Plate 공정 부품으로 재라벨링·재학습·재캘리브레이션을 수행하고, 조명·반사·먼지·진동 등 현장 환경 변수를 4주 파일럿으로 측정해야 합니다.
기업 가치
위치와 방향이 달라지는 부품을 인식해 대응하는 비전 기반 유연 자동화 PoC입니다. 반복 피킹, 방향 정렬, 검사 투입 보조, 오투입 방지 공정으로 확장할 수 있습니다.
