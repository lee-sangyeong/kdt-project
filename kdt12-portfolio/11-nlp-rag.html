사고 상황을 입력하면 근거 기반 과실비율을 제시하는 대시보드

사용자가 교통사고 상황을 자연어로 입력하면 판례·법령·과실비율·조정요소 데이터를 검색해 과실비율과 판단 근거를 제시하는 RAG 기반 자연어 처리 프로젝트입니다. 설명 가능한 답변을 위해 검색 근거와 생성 답변을 분리해 구성했습니다.

Honest Scope
개인 담당이 명확하지 않은 부분은 팀 기준으로 정리
발표자료와 소스 구조에서 이상영 개인 담당 파트가 명확히 분리되지 않은 부분은 개인 성과로 과장하지 않았습니다. 대신 팀 프로젝트의 데이터 구조, RAG 흐름, 서비스 의도를 이해하기 쉽게 정리했습니다.
Problem
교통사고 설명을 판단 가능한 조건으로 변환
사용자 설명은 보통 불완전합니다. 차량 진행 방향, 신호, 차선, 충돌 상황 같은 조건을 확인하고 관련 법령과 과실비율 기준을 검색해야 근거 있는 답변이 가능합니다.
핵심: 생성형 AI가 바로 답을 만드는 구조가 아니라, 먼저 근거 데이터를 검색한 뒤 그 근거를 바탕으로 과실비율과 판단 이유를 설명하도록 구성한 RAG 프로젝트입니다.

Explainability
근거를 분리해 답변 신뢰도를 높임
교통사고 과실 판단은 단순한 텍스트 생성보다 근거가 중요합니다. 검색된 사례와 법령, 과실비율 기준을 보여줘 사용자가 답변의 이유를 확인할 수 있게 했습니다.
Workflow
고객 상담 업무와 유사한 흐름
사고 설명을 받고, 부족한 조건을 묻고, 기준표와 사례를 확인한 뒤 판단을 안내하는 흐름은 보험·법무·고객 상담 현업 프로세스와 닮아 있습니다.

05

직무 연결과 개선 방향

고객 상담, 보험 심사, 품질 클레임, 법무 검토처럼 근거가 필요한 텍스트 업무에는 검색 기반 AI가 적합합니다. 이 프로젝트는 자연어 입력을 구조화 데이터와 연결해 설명 가능한 답변으로 전환한 경험입니다.
— 자연어 처리 RAG 프로젝트 회고
한계
법률·보험 판단은 고위험 영역이므로 최종 결정은 전문가 검토가 필요합니다. 모델 답변은 상담 보조로 제한해야 합니다.
개선
근거 문서 출처, 유사도 점수, 최신 판례 업데이트, 답변 신뢰도 표시를 추가하면 실무성이 높아집니다.
실무 가치
품질 클레임, 고객 문의, 법무 검토 등 근거 검색이 필요한 업무에서 응답 시간을 줄이는 보조 도구로 확장 가능합니다.
