문제 정의

교통사고 과실비율은 유사 사례, 법령, 조정 요소를 함께 봐야 합니다. 단순 키워드 검색으로는 사고 상황의 맥락을 반영하기 어렵기 때문에 자연어 입력과 근거 검색을 연결했습니다.

확인된 구현 구조

  • Streamlit 앱에서 사고 상황 자연어 입력
  • 추가 질문을 통한 사고 정보 보완
  • case_master, law_master, fault_ratio_master 등 데이터 활용
  • rag_backend의 ask, search_evidence, get_verdict 호출 구조
  • 과실비율과 판결문 스타일 설명 제공

서비스 흐름

상황 입력사용자가 사고 설명을 자연어로 작성
정보 보완필요한 조건을 추가 질문으로 확인
근거 검색판례, 법령, 과실비율 기준 검색
판단 생성과실비율과 근거 설명 생성
시각화Plotly와 Streamlit으로 결과 표시
