로또 번호 분포와 공정성 통계 검정

동행복권 로또 당첨번호 데이터를 기반으로 번호 빈도, 연속 번호, 밀집도, 홀짝 비율, 동시출현 조합을 분석하고 Z-score와 카이제곱 검정으로 조작 의혹을 통계적으로 검토했습니다.

문제 정의

로또 번호 분석은 쉽게 예측이나 추천으로 과장될 수 있습니다. 이 프로젝트는 예측이 아니라 실제 번호 분포가 공정한 무작위 추첨 모델에서 크게 벗어나는지 확인하는 데 집중했습니다.

담당 역할

  • 당첨번호 데이터 전처리
  • 번호 빈도, 연속 번호, 밀집도, 홀짝 비율 분석
  • 페어, 트리오, 4개 조합 동시출현 빈도 계산
  • Z-score와 카이제곱 검정 수행
  • 시간축 로지스틱 회귀와 다중검정 보정 결과 해석

검정 흐름

빈도 계산회차별 6개 번호를 펼쳐 출현 횟수 집계
패턴 탐색연속, 밀집, 홀짝, 조합 확인
Z-score기대값 대비 벗어남 측정
Chi-square전체 분포의 이상 여부 검정
결론 제한예측이 아닌 공정성 검토로 해석
