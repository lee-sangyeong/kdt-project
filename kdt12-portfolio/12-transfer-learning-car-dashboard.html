차량 두 대를 1:1로 비교해 구매 판단 기준을 시각화

예비 차량 구매자가 두 차량을 선택하면 가격, 성능, 효율, 공간, 충전 편의성을 비교하고 주행 목적별 가중치로 더 적합한 차량을 판단할 수 있도록 구현한 Streamlit 대시보드입니다. 단순 제원표를 고객 의사결정 UI로 바꾼 프로젝트입니다.

My Scope
1:1 차량 제원 비교 대시보드 담당
차량 두 대를 선택하면 사진, 가격, 최고 출력, 최대 토크, 복합연비, 배기량, 차체 크기, 좌석 수 등 핵심 제원을 한 화면에서 비교하도록 구성했습니다.
UX Goal
제원표를 구매 의사결정 언어로 변환
단순 수치 나열에서 끝내지 않고 가격 대비 출력, 좌석당 가격, 공간 효율, 토크 밀도, 시장 내 백분위 같은 파생 지표로 사용자가 차이를 빠르게 이해하도록 설계했습니다.
핵심: 임원 관점에서는 데이터 분석이 실제 고객 경험과 영업 지원 UI로 연결된 사례입니다. 자동차 제원 데이터를 의사결정 가능한 지표와 화면으로 재구성했습니다.

기능구현 내용비즈니스 가치

목적별 평가출퇴근, 장거리, 가성비, 퍼포먼스, 공간 중심 가중치사용자별 추천 근거 제공

Example Insight
그랜저 하이브리드 vs K8 하이브리드 비교
자료 기준 예시에서는 그랜저 하이브리드가 복합연비, 가격, 전고에서 우세하고 K8 하이브리드는 최대 토크와 전장에서 우세했습니다. 좌석 수, 휠베이스, 전폭, 최고출력, 배기량은 유사하게 해석했습니다.
Metric Insight
고객 언어로 바꾼 파생 지표
출력 가성비는 가격 대비 성능, 좌석당 가격은 탑승 인원 대비 비용, 토크 밀도는 체감 가속력, 공간 효율은 차체 크기 대비 실내 활용성을 설명합니다.
지표정의해석
출력 가성비가격 대비 최고 출력 효율같은 예산에서 성능을 얼마나 확보하는지 비교
좌석당 가격차량 가격 / 좌석 수5인승·7인승 비교 시 비용 공정성 확보
토크 밀도토크를 차량 성능·규모와 연결한 상대 지표힘 있게 밀어주는 체감 성능 비교
시장 포지셔닝가격 중앙값과 출력 중앙값 기준 산점도비싼 차인지, 고성능 차인지 한눈에 확인

05

직무 연결과 개선 방향

자동차 기업에서 차량 제원, 가격, 이미지, 사용자 목적을 연결한 비교 서비스는 고객 경험과 영업 지원에 직접 연결됩니다. 이 프로젝트는 분석 결과를 실제 사용 가능한 대시보드로 구현한 경험입니다.
— 전이 학습 / 자동차 대시보드 프로젝트 회고
한계
차량 정보가 정적 CSV에 의존하므로 최신 가격, 트림, 프로모션, 금융 조건 반영에는 한계가 있습니다.
개선
자동차 API, 금융 금리, 유지비, 보험료, 실구매가 데이터를 연결하면 실제 구매 의사결정력이 높아집니다.
실무 가치
영업 상담, 온라인 견적, 고객 취향 기반 추천, 경쟁 차종 비교 자료로 확장 가능한 자동차 데이터 서비스입니다.
